# 家谱制作器

标准 **uni-app / Vue 3 / JavaScript** 项目，采用 HBuilderX 原生目录结构。页面使用 `view`、`text`、`image`、`picker`、`scroll-view` 等 uni-app 组件，路由与存储使用 `uni.*` API。

## 在 HBuilderX 中运行

1. 使用 HBuilderX 正式版（本机已用 **5.07** 验证），安装或启用 uni-app（Vue 3）编译插件。
2. 选择 **文件 → 导入 → 从本地目录导入**，选中当前 `frontend` 目录。应识别为 uni-app 项目。
3. 本机所需依赖已经安装。复制到其他电脑时，在项目终端执行 `npm ci`。
4. 选中项目，选择 **运行 → 运行到浏览器 → 内置浏览器**，即可使用；Chrome 也支持，若无法打开请参考下方排障说明。
5. 如果此前将此目录作为普通网页项目打开过，请先关闭项目，再重新导入，以刷新项目类型。

不要双击 `index.html` 或使用 Python 静态服务器直接运行源码；它现在是 uni-app 的 Web 入口模板，需要经过 HBuilderX 编译。

若运行到 Chrome 时没有打开页面，HBuilderX 日志出现 `TypeError [ERR_INVALID_URL]: Invalid URL` 且调用栈包含 `startChrome`，本机 HBuilderX 5.07 的启动插件会对 Chrome 的所有调试目标直接解析 URL；开发者工具创建的后台 worker 地址可能为空，从而中断启动。先关闭 Chrome 的开发者工具窗口，再重新运行到 Chrome；也可以直接选择内置浏览器。运行目录应为 `frontend`，不要选择父目录或生成的 `dist` / `unpackage`。以本次控制台输出的地址为准，旧服务占用 5173 时，新服务会使用 5174 等端口。

若浏览器只显示背景，控制台出现 `useShowTabBar` / `Cannot read properties of undefined (reading 'height')`，请在 HBuilderX 停止该项目的旧运行服务，再重新运行到浏览器。删除原生 `tabBar` 或调整页面数量后，旧服务的编译功能开关可能仍然保留；仅刷新浏览器不能解决。使用本次运行日志显示的地址，避免继续访问占用旧端口的服务。无需清除浏览器中的账号或家谱数据。

### 手机 App

在 `manifest.json` 的基础配置中，登录自己的 DCloud 账号并获取 uni-app AppID，然后连接 Android 手机或 iOS 设备，通过 **运行 → 运行到手机或模拟器** 运行。基础资料功能可使用标准基座；后台远程推送需配置 UniPush 2 并使用含 Push 模块的基座或正式包。正式打包还需配置包名、签名及对应平台证书。

项目没有伪造 DCloud AppID，`manifest.json` 中 `appid` 留空等待绑定。App 编译已验证；本次没有连接手机，未进行真机测试。

短信注册和重置密码请求由 `utils/api.js` 发往 FastAPI。H5 调试使用当前网页主机的 8000 端口；手机调试默认使用开发电脑的 `172.16.96.98:8000`。换网络后请将手机与电脑接入同一局域网，并在 `utils/api.js` 修改 `DEFAULT_API_BASE_URL` 为电脑当前 IP，确认后端使用 `--host 0.0.0.0` 启动。验证码 6 位，发送成功后 60 秒内按钮不可重按。

### 微信小程序

在 `manifest.json → mp-weixin.appid` 填写自己的微信小程序 AppID，安装微信开发者工具并启用服务端口后，从 HBuilderX 选择运行到微信小程序。小程序编译已验证，未验证真机或发布。

## 项目目录

```text
App.vue                 应用生命周期与全局样式
main.js                 Vue 3 createSSRApp 入口
manifest.json           uni-app 平台配置
pages.json              页面路由、原生导航栏与 tabBar
uni.scss                全局主题变量
index.html              uni-app Web 入口模板
pages/                  标准 uni-app 页面入口（当前主页面为 pages/index/index.vue）
components/             家族树、关系分析、控件适配、头像等公共组件
utils/                  账号、存储、日期与关系计算
styles/                 主题与图标样式
static/                 本地图片、应用图标等静态资源
tests/                  核心业务回归测试
package.json            运行依赖与测试命令
package-lock.json       锁定依赖版本
```

`node_modules/` 是当前有效依赖；HBuilderX 使用自带 Vue 和 uni-app 编译器。`unpackage/` 是运行时自动生成的目录，可随时删除，不作为源码维护。

当前运行入口已迁移为标准 uni-app Vue 3 页面；原项目参考资源已按 SHA-256 校验后复制到 `static/`，旧页面文件仅作为未启用的历史兼容代码保留，不参与 `pages.json` 路由。

## 已实现

- 新账号首页、纪念日和日历均显示空状态，仅展示当前账号保存的提醒；示范族谱需要手动切换查看。首页按下次日期显示真实倒计时，不再混入示例生日、忌日或祭扫安排。

- 登录只保留一个窗口，统一输入手机号或账号。完整的中国大陆 11 位手机号输入稳定 500 毫秒后自动发送验证码，账号则显示密码框；已注册手机号验证后直接登录，新手机号验证后在同一窗口进入账号设置，无需确认弹窗。

- 服务端账号登录、短信注册/重置、验证恢复、撤销会话与登录设备管理；旧本机 PBKDF2 账号只用于兼容和资料迁移，不冒充云账号。
- 默认开启“在此设备保持登录”，关闭后再次打开会自动恢复有效会话；取消勾选仅保留当前会话。主动退出、会话过期或被撤销后需要重新登录，断网不会删除本机登录记录和家谱缓存。
- 按账号和家族持久保存资料并同步真实数据库：稳定编号、版本检查、离线队列、三方合并及冲突选择。
- 成员录入、查看、编辑、删除；农历换算、头像文字与生平信息。人物关联区可选择已录入的父亲、母亲和配偶，档案中可点击查看关联家人及子女；父母角色随本机缓存、云端同步和备份一同保存。
- 家族树、成员名录、搜索、独立示范族谱、两人关系分析与出生年份推测。
- 按月查看日历、新建/编辑/删除提醒、关联成员、年度重复与到期倒计时。
- 头像上传至私有文件服务并鉴权下载；导出含图片的 JSON、文件/文本导入、旧本机账号资料迁移。
- 站内通知、隐私偏好、手机号绑定、注销、邀请家人、编辑/只读角色、审计都有当前页面入口。

## 数据说明

“我的”主区域直接提供生成 6 位家族邀请码、输入邀请码加入、协作者权限和家谱切换。管理员保留全部权限，可把亲友设为只读或可编辑；邀请码 7 天内有效，只能使用一次。加入共享家谱后，个人家谱独立保留，可直接返回自己的家谱。

手机号登录或手机号注册完成后会询问是否有家族邀请码；没有则进入个人家谱。登录后显示功能导览，可选择今日关闭（按北京时间）或永久关闭，设置保存在服务端账号中。“我的 → 我的所有导览”始终可重新查看并恢复自动导览；关闭导览不会隐藏手机号登录后的邀请码询问。

- 家谱保存在服务端数据库及按账号/家族分区的本机缓存。保存界面明确区分已同步、待同步、失败与冲突，断网修改保留待补传；同步冲突需要选择。
- 图片存放于后端私有文件目录，备份应同时包含数据库与该目录；客户端 JSON 导出会嵌入头像，可跨服务导入。
- 提醒支持公历、农历和清明年度重复；无效闰日、农历闰月不会滚入其他日期。服务端持续生成持久通知，页面关闭后仍生成收件箱。
- Web Push 需 HTTPS/localhost、VAPID 配置和浏览器授权。UniPush 2 需平台凭证、AppID、Push 模块及签名/证书；微信订阅消息需 AppID/AppSecret、模板与用户每次订阅授权。未配置时明确显示未启用，不假称已投递。
- 关系分析依据明确录入的父母/配偶 ID；仅称谓或年龄差会标明资料不足或推测。示范族谱独立，首页封面为示意图片。
- 旧本机资料迁移需要在原存储环境验证旧本机账号密码，并导入已登录云账号；旧数据和导入前恢复副本保留。不同设备/浏览器的本机缓存不能凭账号名自动取得。
- 历史页面保留但未登记路由；当前产品入口是 pages/index/index.vue，不要直接启用历史页面。
